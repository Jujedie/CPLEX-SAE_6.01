# CPLEX-SAE_6.01

## Description
Ce projet utilise CPLEX pour résoudre des problèmes d'optimisation linéaire dans le cadre de la SAE 6.01 (Développement Avancé).
Et des métaheuristiques pour résoudre des problèmes d'optimisation combinatoire.

## Prérequis
- IBM ILOG CPLEX Optimization Studio installé
- Compilateur Java compatible

## Structure du Projet

```
projet/
├── Application/    # Code source de l'application principal
├── CPLEX/          # Fichiers de configuration et bibliothèques CPLEX ainsi qu'une API pour générer des fichiers dates pour l'OPL
├── bin/            # Dossier de sortie pour les exécutables compilés
```

## Compilation
```bash
./compile.sh
```

## Utilisation
```bash
./run.sh
```
